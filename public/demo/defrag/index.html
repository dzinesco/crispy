        Disk Defragmenter
        First time on this drive

        Zen mode is the stare. Press play, then Show Details, and watch the blocks march.

        Game mode is the job. Arrows or WASD move the head. Space picks up a block and drops it on free space. Dragging works. So does a finger.

        Pack every file into one solid run at the front. Unmovable blocks and bad sectors stay put. Finish a file without wandering off for a combo.

        Sometimes the drive changes under you and the job restarts at 10%. That part is not a bug.
